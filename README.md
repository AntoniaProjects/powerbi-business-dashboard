# Power BI Business Dashboard

## Project Overview

This project demonstrates business intelligence reporting using Microsoft Power BI.

The dashboard provides interactive visualizations and KPIs designed to support business decision-making.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling

## Features

* KPI Cards
* Interactive Filters
* Trend Analysis
* Category Breakdown
* Dynamic Visualizations

## Dashboard Objectives

The dashboard was designed to:

* Monitor business performance
* Identify trends
* Support strategic decisions
* Improve reporting efficiency
